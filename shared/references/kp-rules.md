# Правила сборки КП

- **КП на таргет — без контентных кейсов.** Слайды про контент/SMM (органический
  трафик, рилс, охваты) убираются; остаются кейсы по Meta Ads. В КП, где контент
  является частью предложения (комплекс, рилс), контентные кейсы остаются.
- Цены считаются по `pricing.md`. Съёмка в КП называется «мобилограф» /
  «видеограф (проф. камера)», а не «съёмка на мобилку».
- Индивидуальные КП лежат в `html/individual-kp/<slug>/` и `pdf/individual-kp/<slug>.pdf`.
