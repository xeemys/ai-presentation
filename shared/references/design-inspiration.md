# Источники вдохновения для новых дизайнов

Два открытых репозитория, которые стоит **смотреть перед тем, как
проектировать новый слайд/презентацию** — не копировать код кусками, а
доставать оттуда конкретные приёмы (масштаб, сочетание цвета, как подана
цифра) и переносить их в наш собственный `shared/css/deck.css` своими
классами.

## 1. [nexu-io/open-design](https://github.com/nexu-io/open-design) — «OpenDesign»

Открытая платформа генерации дизайна (мультиформатная — не только слайды).
Самое полезное для нас — `design-templates/html-ppt-pitch-deck/example.html`,
готовый HTML pitch-deck. Оттуда взять на заметку:

- **Главная цифра — это `.metric .n`: `font-size:72px; font-weight:900`**,
  залитая градиентом через `background-clip:text` (`linear-gradient(135deg,
  #3b6cff,#7a5cff 55%,#ff5c8a)`), подпись `.metric .l` — 16px, приглушённый
  цвет. Именно этот паттерн (огромная цифра — не подпись) подсказал
  переделку `case-metrics.html`: результат кейса ушёл из мелкого
  `.bottom-row` в крупную акцентную карточку.
- **`.card-accent`** — обычная карточка + `border-top:3px solid var(--accent)`,
  то есть акцент не через тень/заливку всей карточки, а через одну цветную
  грань. Дешёвый способ выделить карточку без нарушения правила «никаких
  теней».
- **`gradient-text`** — приём для заголовков: `background:var(--grad)` +
  `-webkit-background-clip:text` + `color:transparent`. У нас акцент один
  плоский цвет (`--accent`), но для обложек/заголовков можно взять один
  локальный градиентный акцент как исключение, если это оправдано (см.
  ниже про Diskurs).

Не брать: их layout-инфраструктуру, анимации (`anim-fade-up` и т.п. — не
нужны для печати в PDF), JS-фреймворк генерации.

## 2. [marvkr/better-design](https://github.com/marvkr/better-design) — «Better Design»

MCP-сервер + каталог из 31 дизайн-системы для shadcn/ui (React/Tailwind,
токены под живые интерфейсы, не под печатные слайды). Полезен не как
готовый код (он react-компоненты, нам не подходят напрямую), а как
**библиотека референсов токенов** — можно быстро посмотреть, как
конкретный «вайб» раскладывается на цвет/радиус/тень/блюр, и перенести
эти числа в свою CSS-переменную:

- **`glassmorphic-dark`** (`components/glassmorphic-dark/globals.css`) —
  фон почти чёрный (`oklch(0.14 0 0)`), карточка — `background:white/6%`
  + `border:white/12%` + `backdrop-blur:2xl` + тень
  `0 8px 32px rgba(0,0,0,.5), inset 0 0 8px rgba(255,255,255,.06)`,
  радиус `1.25rem`. Это ровно тот frosted-glass эффект, что и в карточках
  маркетинг-кита Diskurs (см. ниже) — оттуда взяты конкретные числа
  прозрачности/блюра для наших `.card.glass`.
- **`corporate-fintech`** — светлая, данные-плотная, синий акцент; полезна
  как альтернативный набор чисел, если понадобится вариант «светлый,
  но корпоративный» отдельно от нашей текущей системы.
- Полный список 31 системы (`README.md` репозитория) — смотреть, когда
  нужен новый «вайб» под конкретного клиента (например, тёмный технологичный
  для IT-продукта — `vercel`/`linear`; премиальный светлый — `apple`).
  Смотреть страницу нужной системы **только для чисел** (цвет/радиус/тень),
  а не переносить их React-компоненты.

Не брать: сами `.tsx`-компоненты (shadcn/React, не подходит для статичного
HTML), Radix-примитивы, анимации на Framer/`tw-animate-css`.

## 3. Бренд-референс: маркетинг-кит Diskurs (2026)

Не открытый репозиторий, а собственный маркетинг-кит агентства (PDF,
39 страниц) — ориентир по «красиво и презентабельно» для будущих деков,
если нужен более выразительный (не строго-светлый) вариант:

- Тёмная обложка: navy→electric-blue градиент + зерно/шум текстура,
  огромный bold заголовок (условно 80–120px), маленький тег-лейбл снизу.
- Статистика — 2×2 сетка **glassmorphic-карточек** на тёмном/фото-фоне
  (полупрозрачная заливка + блюр + тонкая светлая обводка), крупная
  цифра + короткая подпись под ней.
- Разделы-обложки категорий (например «FMCG CASES») — тот же тёмный
  градиент + 3D-иконки/предметная фотография, крупный заголовок в 2 строки.
- Отдельные кейсы — **наоборот, светлые**: логотип + название, синий
  callout-блок «Что мы сделали», 2 плоские светлые карточки-стата с
  зелёной круглой иконкой-стрелкой вверх, 1–2 фото снизу.
- Закрывающий слайд контактов — снова тёмный, силуэт-фото + подчёркнутые
  ссылки.

Вывод для наших декоров: **не всё в тёмном** — Diskurs сам чередует
тёмные обложки/разделители со светлыми страницами кейсов. Это
согласуется с нашей системой (`.slide` светлый по умолчанию), но даёт
право на **точечный тёмный/градиентный вариант** для обложки и
закрывающего слайда — не переписывать всю систему в тёмную.

## Как этим пользоваться

Перед тем как проектировать новую презентацию (или подраздел с другим
настроением) — **шаг 0** до `shared/blocks/README.md`:

1. Открыть `design-templates/html-ppt-pitch-deck/example.html` в
   `nexu-io/open-design` — посмотреть, как расставлены акценты/масштаб
   цифр в готовом pitch-deck.
2. На [better-design.com/design-systems](https://better-design.com/design-systems)
   (или в клоне репозитория, `components/<name>/globals.css`) найти
   1–2 системы, чей «вайб» ближе к задаче, и выписать числа (цвет, радиус,
   тень/блюр).
3. Перенести 2–3 конкретных приёма как **новые переиспользуемые классы**
   в `shared/css/deck.css` (не одноразовый inline-стиль в одном слайде),
   с комментарием, откуда взят приём.
4. Собирать слайды по-прежнему из `shared/blocks/` — новые приёмы должны
   лечь в существующие компоненты (`.card`, `.stat-big`, `.kicker`...)
   или стать явным новым модификатором (`.card.glass`, `.slide.dark`),
   а не разовым `style="..."` на одном слайде.
