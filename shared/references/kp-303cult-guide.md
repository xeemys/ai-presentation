# Как собирать КП для 303.cult — подробная инструкция

Для тех, кто (человек или Claude) делает новое коммерческое предложение агентства
**303.cult**. Читать целиком перед первой сборкой. Цены и ставки — в
[`pricing.md`](pricing.md), краткие правила — в [`kp-rules.md`](kp-rules.md).

---

## 1. Принцип

КП — это **всегда одна и та же полная презентация** (обложка, «кто мы», услуги, кейсы,
тарифы, контакты). Индивидуальное КП = копия основной, где **меняются только слайды с
тарифами** (и, по правилу ниже, убираются контентные кейсы, если предлагается чистый таргет).
Не делать КП с нуля и не выкидывать кейсы, кроме случаев из раздела 4.

Клиент в КП **не называется** (ни на титуле, ни в тексте): КП универсальное, адресата
подставляют устно.

## 2. Где что лежит

| Что | Где |
|---|---|
| Основная КП (20 слайдов) | `html/303cult-kp/index.html`, PDF `pdf/303cult-kp.pdf` |
| Индивидуальные КП | `html/individual-kp/<slug>/index.html`, PDF `pdf/individual-kp/<slug>.pdf` |
| Дизайн-система | `shared/css/deck.css` + тёмная тема `shared/css/theme-dark.css` |
| Шрифт | `shared/fonts/inter/` (статичные Inter 400–900, полный набор глифов: есть ₸, →, ✓) |
| Фоны, логотип, рилсы | `html/<slug>/assets/` (`bg/bg-cult.jpg`, `bg/bg-flat.jpg`, `bg/bg-2…5.jpg`, `logo.jpg`, `reels/*.jpg`) |
| Цены и ставки | `shared/references/pricing.md` |
| Скрипты | `scripts/inline-deck.mjs` (встроить ресурсы), `scripts/export-pdf.mjs` (PDF) |

## 3. Бренд 303.cult

- Тёмная тема: фон `#202020`, текст `#F5F5F3`, акцент коралловый `#F2583A` (из логотипа).
- Все слайды без своего фона лежат на текстуре `bg-flat.jpg` (правило в `<style>` в `<head>`),
  обложка и последний слайд — на текстуре `bg-cult.jpg` (надпись «cult»), слайды 2 и 3 — на
  `bg-2.jpg` и `bg-4.jpg`.
- Заголовки — Inter 800/900; крупные цифры цены — класс `stat-big`; акцентная карточка
  с итогом — `background:var(--accent)`.
- **Никаких `box-shadow`/blur** на содержимом слайда (дают артефакты в PDF).
- Контакты на последнем слайде: Instagram `303.cult`, WhatsApp `+7 705 123 49 33`. Сайта нет.
- Формулировки съёмки: **«мобилограф»** и **«видеограф (проф. камера)»**. Не «съёмка на мобилку».

## 4. Структура основной КП (20 слайдов)

| № | Слайд | Менять в индивидуальном КП? |
|---|---|---|
| 1 | Обложка «Трафик, который окупается» + 3 факта | нет |
| 2 | Кто мы (принципы, $1 000 000+, ~530% ROMI) | нет |
| 3 | Что мы делаем (6 услуг) | подпись снизу: «Условия сотрудничества — на следующих слайдах» вместо «Полную тарифную сетку…» |
| 4 | Обзор 5 проектов | нет |
| 5–14 | 5 кейсов Meta Ads (по 2 слайда: результат + скрины кабинета) | нет |
| 15–17 | **Контентные кейсы** (система контента, 15 000 подписчиков, охваты рилсов) | **убрать, если КП на чистый таргет** |
| 18 | Тарифы — 4 карточки | **заменить** |
| 19 | Лендинги и продакшн | **заменить/удалить** (обычно сливается с 18) |
| 20 | Контакты («Готовы обсудить ваш проект?») | нет |

**Правило про контентные кейсы.** КП только на таргет → слайды 15–17 удаляются
(в них в `top-meta` написано «Контент ·»). Если контент входит в предложение (комплекс, рилс,
таргет + контент) → кейсы остаются.

## 5. Пошагово: новое индивидуальное КП

1. **Определить состав и цену** по `pricing.md` (раздел 6 ниже). Сверить арифметику вручную.
2. **Выбрать образец** и скопировать папку (HTML самодостаточный, ресурсы уже встроены):

   | Если КП… | Брать за основу |
   |---|---|
   | таргет + N видео, один тариф | `html/individual-kp/target-5video-mobilograf` |
   | таргет, два тарифа рядом (мобилограф / видеограф) | `html/individual-kp/target-10video-impro` |
   | таргет + контент, сумма с «+» и «=» | `html/individual-kp/kp1-target-content` |
   | комплекс со скидкой (зачёркнутая сумма) | `html/individual-kp/kp2-target-content` |
   | оффер без цен (доля от оплаты) | `html/individual-kp/reels-target-60pct` |
   | что-то новое | `html/303cult-kp` (основная) |

   ```bash
   cp -r html/individual-kp/<образец> html/individual-kp/<новый-slug>
   ```
   Slug — kebab-case, говорящий: `kp3-target-content`, `target-7video-pro`.
3. **Убрать контентные кейсы**, если КП на чистый таргет (раздел 4). Каждый слайд — это
   `<section class="slide …">…</section>`; контентные имеют `top-meta">Контент ·`.
4. **Заменить тарифный слайд** (в образцах он помечен комментарием `<!-- 18 — … -->`). Менять
   только числа, пункты списков и подпись; вёрстку не трогать. Крупную цену писать так:
   `350 000 ₸` (пробелы-разделители тысяч, знак ₸ через пробел).
5. **Перенумеровать** подвал каждого слайда: `<b class="num">NN</b> / TOTAL`, где TOTAL — число
   слайдов. Заодно поправить номера в HTML-комментариях `<!-- NN — … -->`.
6. Если подпись на слайде 3 ещё про «тарифную сетку» — заменить (см. раздел 4).
7. **Экспорт в PDF:**
   ```bash
   npm install                       # если нет node_modules (в новом контейнере их нет)
   node scripts/inline-deck.mjs individual-kp/<новый-slug>   # только если добавляли новые картинки/CSS-ссылки
   npm run export -- individual-kp/<новый-slug>
   ```
   Результат: `pdf/individual-kp/<новый-slug>.pdf`.
8. **Проверка** (раздел 7), затем `git add`, коммит, `git push -u origin <ветка>`, отправить PDF.

## 6. Цены: как считать

Полные ставки и примеры — в `pricing.md`. Коротко:

- **Таргет** = база (250 000 ₸; **150 000 ₸ только для Импро**) + видео × (20 000 мобилограф /
  40 000 видеограф). Статика в таргете — «до 20», отдельной цены нет.
- **Контент** = рилсы × 20 000 + статики × 4 700 + сторис × 1 360.
  Порядок трат всегда: рилсы > сторис > статика.
- **Итого** = таргет + контент. Если нужна круглая цена (например, «комплекс 600 000») —
  сумма не меняется, а на слайде показывается **зачёркнутая настоящая сумма**, крупная цена
  комплекса и строка «Выгода комплекса — N ₸» (N = сумма − цена комплекса). Ставки под цену
  не подгонять, пока клиент/руководитель явно не попросит «изменить юнитку».
- Если ставки меняются — **обновить `pricing.md`** и пометить старые как заменённые.
- Перед согласованием цены сверить маржу по [`unit-economics.md`](unit-economics.md) (внутренний документ; в КП и клиенту не показывать).

Проверка суммы перед сборкой:
```python
таргет = 250_000 + видео*20_000          # или 150_000 для Импро
контент = рилсы*20_000 + статики*4_700 + сторис*1_360
print(таргет, контент, таргет+контент)
```

## 7. Чек-лист перед отправкой

- [ ] Слайдов столько, сколько ожидаете; последний слайд — контакты.
- [ ] Номера `NN / TOTAL` идут подряд, TOTAL правильный на всех слайдах.
- [ ] Для чистого таргета в PDF нет слов «Контент ·» и «органическ»; для контентного — кейсы на месте.
- [ ] Цены на слайде сходятся с ручным расчётом (проверить сумму и «выгоду»).
- [ ] Нет названия клиента; нет цены там, где оффер без цен.
- [ ] В PDF только шрифты Inter (никаких `LiberationSans`/`DejaVu`); знак ₸ отрисован.
- [ ] Посмотреть тарифный слайд глазами: ничего не налезает на верхнюю шапку и номер, есть воздух
      между заголовком и карточками.
- [ ] Контакты верные (Instagram и WhatsApp), нет плейсхолдеров `[…]`.

Быстрая автопроверка PDF:
```python
import pymupdf, re
d = pymupdf.open('pdf/individual-kp/<slug>.pdf')
print(d.page_count, sorted({f[3] for p in d for f in p.get_fonts(full=True)}))
print([re.findall(r'\d\d / \d\d', p.get_text())[-1:] for p in d][-4:])
```

## 8. Типичные ловушки

- **Нет `node_modules`** после перезапуска контейнера → `npm install`, иначе `Cannot find package 'playwright'`.
- **Шрифт в PDF откатывается на системный** (LiberationSans): экспорт уже принудительно загружает все
  начертания; если проблема вернулась — проверить `scripts/export-pdf.mjs` (блок с `document.fonts`).
- **Символ ₸, →, ✓ вместо квадратиков** — нужен полный Inter из `shared/fonts/inter/`; обрезанные
  подмножества шрифта (латиница+кириллица) не содержат этих знаков.
- **Теги `</style>` внутри комментариев CSS** ломают встроенный HTML — не писать.
- **Фон слайда задан через `url('assets/…')`** — `inline-deck.mjs` его встраивает; после правки CSS
  в `shared/` запускать с `--refresh-css`.
- **Удаление слайдов регулярками**: границы — `<section class="slide` … `</section>`; после
  удаления обязательно перенумеровать подвалы, иначе «05 / 20» при 16 слайдах.
- Слово «комплекс» и цена «600 000 ₸» из основной КП **не переносить** в индивидуальные без
  пересчёта: там другие составы.

## 10. Что делать, если запрос неполный

Если не хватает данных — **спросить**, а не придумывать: цена контента без ставок, состав
(сколько видео/статик/сторис), для кого (Импро или нет), чистый таргет или с контентом.
Расчёт предлагать с формулой, чтобы можно было быстро поправить.
